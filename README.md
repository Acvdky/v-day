# Valentine's Day Website

## Overview
A personalised Valentine's Day website created as a personal front-end web development project. The website combines themed visuals, custom page layouts, and interactive content.

## Live Demo

[View the Valentine's Day Website](https://acvdky.github.io/v-day/)

## Technologies Used
- HTML — webpage structure and content
- CSS — styling, layouts, and visual presentation
- Visual Studio Code — code editing and development

## Project Structure
- `index.html` — main website entry point
- `valentine.html` — additional Valentine's Day webpage
- `images/` — image assets used by the website

## Getting Started
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Project Background
This personal project was created to explore web design, webpage customisation, and front-end development through a themed website.
